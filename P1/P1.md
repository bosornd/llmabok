- T3. Pydantic 모델을 사용하여 출력 형식을 정의한다.
    - Python 3.6부터 class 멤버 변수에 type annotation을 붙일 수 있다.
    - Pydantic은 annotation으로부터 type 검증 등을 제공하는 모듈이다.
    ```python
    from pydantic import BaseModel, Field
    class Capital(BaseModel):
        capital: str = Field(description="수도")

    from langchain_core.output_parsers import PydanticOutputParser
    output_parser = PydanticOutputParser(pydantic_object=Capital)
    print(output_parser.get_format_instructions())
    ```
